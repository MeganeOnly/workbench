# 我的工作台（Workbench）

本地网页版工作台：把常用操作做成按钮，点一下即执行。

> 给 AI 助手 / 开发者：修改本项目的**权威流程与架构说明**见同目录 [DEV.md](DEV.md)（按钮配置、重启、验证、易错点），修改前必读。用户可能在任何新的对话中提出功能需求。

- 访问地址：`http://127.0.0.1:3180`（仅本机可访问）
- 启动方式：双击 `start-workbench.bat`，会自动清理旧进程、后台启动服务并打开浏览器

## 当前按钮

| 按钮 | 行为 |
|---|---|
| DSH 服务（toggle） | 一个按钮：DSH 停止时显示绿色"启动 DSH"；运行中显示红色"停止 DSH"，点击自动切换 |
| Push 队列 | 卡片上实时显示 Anki 队列待推送数量（待推送 X / 共 Y 条，有待推送时高亮）；点击在 Anki 工作目录新建一个 DSH 对话并自动发送 push，然后打开 DSH 页面 |
| Anki | 通过开始菜单快捷方式（`Anki.lnk`）打开 Anki；已在运行则激活窗口到前台。徽章实时显示「运行中/已停止」（按进程检测） |
| SM18 | 打开 `F:\SM学习分享, 有能力请支持正版\sm18.exe`（SuperMemo 18）；已在运行则激活窗口到前台。徽章实时显示「运行中/已停止」（按进程检测） |
| 整理 Inbox（dida） | 每晚 21:00 后出现：在 `F:\AllWorkSpace` 新建 DSH 对话并自动发送「整理inbox」，然后打开 DSH 页面；点过一次当天隐藏 |
| 安排今日任务（dida） | 全天可见：在 `F:\AllWorkSpace` 新建 DSH 对话并自动发送「安排今日任务」，然后打开 DSH 页面；点过一次当天隐藏 |
| 周报（dida） | 每周日 22:30 后出现：在 `F:\AllWorkSpace` 新建 DSH 对话并自动发送「该周报了」，然后打开 DSH 页面；点过一次本周隐藏，下周日自动恢复 |

> **自动添加快捷方式**：样式面板「快捷方式」区——填程序路径（.exe / .lnk）点「添加按钮」即自动生成卡片（自动提取软件图标、自动配"未运行则启动 / 已运行则激活"），无需手改配置；已添加列表可随时删除。全程不消耗 AI token。

按钮右侧徽章实时显示端口 3080 是否在运行。

### 卡片墙（Bento 布局）

中间区域是 **8 列 Bento 卡片墙**：功能按钮与信息卡混排。**点击卡片任意位置即可执行**（功能卡）；**按住卡片任意位置拖动**即可换位（轻点与拖动自动区分，顺序保存在浏览器 localStorage 中，刷新后保留）。

- 内置信息卡：**DeepSeek 余额**（点击跳转用量页）、**系统状态**（DSH 3080 / 工作台 3180）、**书签**（卡片右上角 **+** 可直接添加网页；侧栏与书签卡内的书签都可**按住任意位置拖拽排序**，顺序保存在服务端）、**滴答今日任务**、**滴答专注**（Anki 队列数量已并入 **Push 队列** 卡显示，不再单独占卡）、**RSS 订阅**（见下）
- 卡片尺寸档位：`size: "large"`（半行 4 列）/ `"wide"`（半行 4 列）/ `"small"`（四分之一行 2 列），不写默认 `wide`
- 小屏自动降为 2 列 / 1 列
- 样式面板「布局」区有**侧边栏开关**：可随时启用/禁用书签管理侧栏（禁用后仍可通过书签卡的 + 添加书签）

### 顶栏快速搜索

顶栏搜索框：输入关键字**实时过滤**卡片墙与侧栏书签（按名称/描述/网址匹配），**回车**执行顺序中第一个匹配（功能卡 = 点击执行，书签 = 打开网页），**Esc** 清空恢复。按 **/** 键可随时聚焦搜索框。不需要可在「样式 → 偏好 → 搜索框」一键关闭。

### RSS 订阅卡

「样式 → RSS 订阅」区可添加任意 RSS / Atom 订阅源（名称 + 地址），卡片上按源分组显示最新条目（每源 8 条，点击标题打开原文；点击源名打开源站点）。适合订阅文献更新（如 arXiv 分类源 `http://export.arxiv.org/rss/cs.AI`，把 `cs.AI` 换成你的方向）或博客/资讯。

- 服务端每 15 分钟缓存一次抓取，前端 10 分钟刷新；单源抓取失败自动沿用上次内容并淡化显示
- 最多 12 个源；不需要整个卡片时在「偏好 → RSS 订阅卡」一键关闭（关闭后不抓取）

### DeepSeek 峰谷定价提醒

顶栏右侧有**时段指示器**：高峰时段（北京时间 9-12 / 14-18）显示橙色「高峰价 · 剩余 X 小时 Y 分」并带脉冲动画；空闲时段显示绿色「空闲价 · 半价」。Push 卡片在高峰时段额外显示费用提醒行。判定基于本机时间，每分钟自动刷新。

新增主题/布局只需在 `style.css` 追加 `body[data-theme="xxx"]` / `body[data-layout="xxx"]` 规则，并在 `index.html` 面板与 `app.js` 选项表中登记即可。

### Push 卡片工作原理

点击"Push 卡片"后，工作台通过 dsh web 的本地 API（127.0.0.1:3080）执行两步：

1. `session.create` — 在 `F:\Anki - DeepSeek -Harness` 目录创建一个全新对话
2. `session.prompt` — 向该对话发送 `push`，触发 anki-card-push skill 流程

完成后自动打开 DSH 页面，你会在会话列表顶部看到最新创建的 push 对话（状态为执行中）。每次点击都是全新对话，天然满足"一个对话最多三次、多了换新"的需求——每次 push 都是干净的上下文。

## 如何新增按钮（后续需求扩展）

编辑 `buttons.json`，在 `buttons` 数组中追加一项即可，无需改动代码。

### 普通按钮

```json
{
  "id": "my-tool",
  "name": "我的工具",
  "description": "按钮说明",
  "size": "small",
  "command": "cmd.exe",
  "args": ["/c", "call \"C:\\path\\to\\script.bat\""],
  "port": 3080,
  "color": "#10b981"
}
```

字段说明：

- `id`：唯一标识（URL 使用）
- `name` / `description`：界面显示
- `size`：可选，卡片尺寸 `large` / `wide` / `small`，默认 `wide`
- `command` / `args`：要执行的命令。执行 .bat 一般用 `cmd.exe /c call "..."`，窗口自动隐藏
- `port`：可选，填端口号后按钮会实时显示该端口"运行中/已停止"
- `color`：按钮颜色，任意十六进制色值

### 切换按钮（toggle，按状态变色）

适合"启动/停止同一个服务"的场景：一个按钮根据端口状态自动显示对应动作并变色。

```json
{
  "id": "my-service",
  "name": "我的服务",
  "description": "点击启动或停止",
  "port": 3000,
  "toggle": {
    "start": {
      "label": "启动服务",
      "color": "#047857",
      "command": "cmd.exe",
      "args": ["/c", "call \"C:\\path\\to\\start.bat\""]
    },
    "stop": {
      "label": "停止服务",
      "color": "#dc2626",
      "command": "cmd.exe",
      "args": ["/c", "call \"C:\\path\\to\\stop.bat\""]
    }
  }
}
```

字段说明：

- `port`：必填，根据该端口是否监听自动决定执行 `start` 还是 `stop`
- `toggle.start` / `toggle.stop`：各自包含 `label`（按钮文字）、`color`（按钮颜色）、`command` / `args`（执行的命令）

修改保存后，刷新工作台页面即可看到新按钮。

## 项目结构

```
workbench/
├── server.js            # 本地服务（端口 3180），零依赖 Node 实现
├── buttons.json         # 按钮配置（唯一需要编辑的文件）
├── feeds.json           # RSS 订阅源（设置面板自动增删，自动生成）
├── public/              # 前端页面
│   ├── index.html
│   ├── style.css
│   └── app.js
├── start-workbench.bat  # 一键启动脚本
├── test-click.mjs       # 点击接线回归测试（node test-click.mjs，无副作用）
└── workbench.log        # 服务日志（启动后生成）
```

## 说明

- 工作台服务仅监听 `127.0.0.1`，不会对外网开放。
- 手动启动服务：在 `workbench` 目录执行 `node server.js` 即可。
- 运行记录仅保存在内存中，工作台服务重启后清空。
